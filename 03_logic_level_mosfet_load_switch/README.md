# Logic-Level N-Channel MOSFET Load Switch

A compact PCB designed in **KiCad** that demonstrates **low-side switching** of a **12 V DC load** using an **IRLZ44N logic-level N-channel MOSFET**. The circuit is controlled by a **5 V logic input**, making it suitable for interfacing microcontrollers with higher-voltage DC loads.

---

## 📖 Project Overview

This project implements a **logic-level N-channel MOSFET load switch** for controlling a **12 V DC load** using a **5 V control signal**. The circuit uses an **IRLZ44N MOSFET** configured as a **low-side switch**, allowing a low-voltage logic signal to safely switch higher-voltage loads.

To improve reliability and protection, the design includes:
- A **100 Ω gate resistor** to limit transient gate current during switching.
- A **10 kΩ gate pull-down resistor** to ensure the MOSFET remains OFF when no control signal is present.
- A **1N4007 flyback diode** to protect the MOSFET from voltage spikes generated by inductive loads.
- An **LED indicator** to visually indicate the switching state.

The PCB was designed with a compact **40 mm × 40 mm** footprint and routed entirely on the **bottom copper layer**, providing practical experience in efficient component placement and single-layer PCB routing.

## ⚙️ Circuit Description

The circuit uses an **IRLZ44N logic-level N-channel MOSFET** configured as a **low-side switch**. When a **5 V control signal** is applied to the MOSFET gate, the device turns ON, allowing current to flow from the **12 V supply** through the load to ground.

A **100 Ω gate resistor** limits transient gate current during switching, while a **10 kΩ pull-down resistor** keeps the MOSFET in the OFF state by discharging the gate whenever the control signal is removed.

A **1N4007 flyback diode** is connected across the load to suppress reverse voltage spikes generated by inductive loads, protecting the MOSFET from damage. An **LED** is included to provide a visual indication of the output switching state.
